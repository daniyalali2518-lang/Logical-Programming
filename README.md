# Implementation of Conditional Logic and Decision-Making in C Programming

This assignment focuses on applying logical reasoning and decision-making techniques through C programming.
It involves solving six practical problems using conditional statements, comparison operators, and arithmetic operations.
Each task demonstrates how programming logic can be used to evaluate conditions and generate appropriate results.
The programs strengthen fundamental problem-solving and analytical skills.

1. Palindrome Number Checker: Uses digit extraction and conditional statements to check whether a five-digit number is equal to its reverse.
2. Youngest Age Finder: Uses nested decision-making conditions and logical operators to identify the youngest among three individuals.
3. Day Calculator: Uses leap-year calculations, arithmetic operations, and conditional statements to determine the day of January 1 for a given year.
4. University Admission Allocator: Uses multiple if-else conditions to allocate university departments according to F.Sc. and NTS marks.
5. Wolf and Sheep Distance Checker: Uses absolute-distance calculations and conditional statements to determine which wolf is closer to the sheep.
6. Library Fine Calculator: Uses conditional statements to calculate library fines according to the number of delayed days and determine membership cancellation.
